# Курс домашньої електрики

Сайт на звичайних файлах. Змінювати зміст можна прямо на GitHub, без програмування.

## Як змінити існуючий урок
1. Відкрий на GitHub папку `lessons` і файл уроку, наприклад `01-osnovy.md`.
2. Натисни значок олівця (Edit), внеси зміни, потім Commit changes.
3. Через хвилину Vercel сам оновить сайт.

## Формат уроку
- `# Заголовок` для назви, `## Підзаголовок` для розділів.
- `**жирний**` для виділення, `- пункт` для списків.
- `> текст` для виділеного блоку (наприклад, безпека).
- `? Питання | Відповідь* | Інша | Інша` для тесту (зірочка позначає правильну).
- `[!Текст кнопки](trainer.html#1)` для кнопки на рівень тренажера. Звичайне посилання: `[текст](адреса)`.

## Як додати новий урок
1. У папці `lessons` натисни Add file → Create new file, назви його, наприклад, `02-avtomat.md`, і встав текст уроку.
2. Відкрий `course.json` і додай у потрібний модуль рядок:
`{"type":"lesson","id":"02-avtomat","title":"Урок 2. Автомат і кабель"}` (не забудь кому між елементами).

## Як додати або змінити вправу в тренажері
1. Відкрий сайт із додатком `?author=1`: `адреса-сайту/trainer.html?author=1`.
2. Натисни «Новий рівень» (або вибери існуючий), розстав елементи, заповни назву, завдання і підказку.
3. Натисни «Створити JSON». Текст скопіюється автоматично.
4. На GitHub відкрий `levels.json`, вставте скопійований блок у кінець списку (перед останньою `]`, з комою після попереднього рівня).
5. Додай рівень у `course.json`: `{"type":"level","id":"7","title":"Назва"}`.
